# Repository discovery report

Use one report per declared source scope. Replace prompts with actual evidence;
omit inapplicable detail with a reason. This is an external working artifact,
not canonical documentation, a packet v1 payload or an approved recovery plan.

## Scope and result

- Outcome: `mapped` or `incomplete`; scope-specific meaning and stop reason.
- Repository/snapshot, selection method, supplied Git evidence and verification
  limits; dirty patch or clean-state evidence.
- Readers, authorized/excluded paths, dependency-access limits and budget.
- Interaction mode: unattended or guided; requested checkpoints and current
  pending/answered/waived state, if any.
- Procedure source/revision, actual model identifier or `unavailable`.
- Actual tools; host enforcement and activity capture available or unavailable.
- Actual callable read/search/symbol operations, any failed or unavailable
  capability, the substitute survey method and remaining investigation limits.

A topic can retain or extend existing material; it is not automatically a new
page. Distinguish relevant material located from detailed adequacy verified.
State whether evidence was only read or actually executed; an unverified example
is a research lead, not a runnable/check-passed claim. Name missing routes.
Group helpers and related topics with a reason; keep cross-Module flows visible.
These assignments are proposals, not documentation approval or a recovery queue.

## Coverage and handoff

Record inspected/not-inspected discovery surfaces and candidate dispositions:
mapped, grouped, deferred, inaccessible or excluded with a source-backed reason.
Separate essential survey gaps from delegated detail questions and unresolved
authority decisions. A located contradiction can be a research/decision topic
without preventing an otherwise supported observational map. State which
uncertainties prevent a responsibility, relationship or handoff from being
established. Distinguish proposed next work from authorized work.
Use stable IDs across map revisions and retain the prior snapshot/reference
when supplied; later findings can revise the map, not silently certify it.
For a paused guided run, name the pending decision and next bounded action;
for resumption, retain the exact prior report reference and drift disposition.
